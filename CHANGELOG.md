# Changelog

## 0.1.0 — 2026-11-06 (prerelease)

Initial versioned distribution of Relyon Dev and On Site.

- Preserved compiled Relyon Dev site with local media and bundled demonstration.
- Payload collections for pages, posts, projects, testimonials, media and reusable content.
- On Site dashboard, colored navigation, dark/light themes and compact navigation support.
- Project title synchronization and existing page/post content bridge.
- Live preview and text editing bridge to native Payload forms.
- Local semantic search with Ollama, chunked embeddings, persistent retries and re-indexing.
- Fresh-install content restoration with ID remapping and administrator creation.
- Documentation, repository checks and automated semantic/TypeScript tests.
- Release lockfile updates Next.js to 16.4.5 and DOMPurify to 3.4.17; no high/critical npm audit findings remain at release verification.

Known limits: no original Next.js landing-site source; no contact delivery; sample content and legal review outstanding; visual building is limited; semantic ranking quality is not yet broadly evaluated. This is a development prerelease.
